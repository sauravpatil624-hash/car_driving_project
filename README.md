# Car Driving Management System

A web-based **Car Driving Management System** developed to simplify the management of a driving school. The system provides an organized platform for managing users, driving packages, enquiries, and other driving school-related operations.

## 🚀 Features

* User Registration and Authentication
* User Management
* Driving Package Management
* Enquiry Management
* Database-driven application
* Admin-side management functionality
* Simple and user-friendly interface
* Backend integration using PHP and MySQL

## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment:** XAMPP
* **Tools:** VS Code

## 📂 Project Structure

* `cms/` – Main application files
* `SQL File/` – Database SQL file
* `readme.txt` – Project information

## ⚙️ How to Run the Project

1. Install and open **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Copy the project folder into:
   `C:\xampp\htdocs\`
4. Open **phpMyAdmin** and create a database.
5. Import the SQL file from the `SQL File` folder.
6. Update the database configuration in the project if required.
8. Open the project in your browser:

   `http://localhost/Car-Driving-Management-System/`

## 🎯 Purpose

This project was developed as an academic web development project to gain practical experience in **PHP, MySQL, frontend development, database management, authentication, and CRUD-based web applications**.
